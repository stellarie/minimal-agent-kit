# Words to check

Each row gives a misused word or phrase, the problem with it, and the plainer choice.

| Word or phrase | Problem | Write instead |
|---|---|---|
| Allude / refer | Allude hints indirectly; refer names a source directly. | refer, for a named source |
| Alternate | Means every other one, or a stand-in, not one of two options. | alternative, for one of two options |
| Among / between | Among fits three or more things; between fits two. | among for groups; between for two items |
| And/or | Clumsy and ambiguous. | or, both, or the full list of options |
| As to whether | Wordy. | whether |
| As yet | Wordy. | yet, placed before the verb |
| Can | Means is able, not permission. | may, for permission |
| Case | Usually filler. | cut it, or give the number |
| Certainly | Empty intensifier. | cut it |
| Character | Usually redundant with a plain noun. | cut it, or name the trait |
| Compare | Compare to shows analogy; compare with shows differences. | compare with for like items; to for analogy |
| Comprise | Means includes; the whole comprises its parts. | the whole comprises the parts, or parts make up the whole |
| Currently | Redundant with the present tense. | now, or drop it |
| Different than | The standard form is different from. | different from, other than, or unlike |
| Disinterested | Means impartial. Uninterested means not interested. | impartial, for no bias; uninterested, for not interested |
| Due to | Loosely used for because of. | because of, or due to after a noun |
| Each and every one | A pitchman's phrase. | each, or every one |
| Effect / affect | Effect is a noun for result; affect is a verb for influence. | effect (noun), affect (verb for influence) |
| Etc. | Avoid after such as or for; avoid when the list is incomplete. | name the items, or close a nearly complete list |
| Farther / further | Farther is distance; further is time or quantity. | farther for distance; further for time or quantity |
| Finalize | Pompous and ambiguous. | complete, settle, or finish |
| However | Avoid starting a sentence with it, meaning nevertheless. | but, or place however after the first clause |
| Imply / infer | The writer implies; the reader infers. | the writer implies; the reader infers |
| In terms of | Usually padding. | state the relationship directly |
| Interesting | Announcing interest does not make content interesting. | cut it; state what the content shows |
| Irregardless | Wrong. | regardless |
| Kind of / sort of | Literal sense only in formal prose. | rather, somewhat, or name the category |
| Less / fewer | Less refers to quantity; fewer refers to countable items. | fewer, for countable items |
| Like | Governs nouns and pronouns; before a clause, use as. | as, before a clause or phrase |
| Literal | Overused for exaggeration or dramatic metaphor. | use only for the literal sense |
| Most | Not an intensifier, and not a substitute for almost. | almost, nearly, or most of |
| Nice | Vague. | a precise word for the quality |
| Personally | Usually filler. | cut it |
| Secondly | The -ly form is stale. | second, third |
| State | Means express clearly; not a synonym for say. | say, write, or give |
| Than | A comparison can drop an essential word. | name the missing word in the comparison |
| That / which | That defines and takes no comma; which adds a fact and takes commas. | that without a comma, or which with commas |
| The foreseeable future | Vague cliche. | a stated timeframe, such as next quarter |
| This | Vague when it points back to a whole sentence. | this plus a noun, such as this change |
| Type | Not a synonym for kind. | kind, in general prose; type, for a data type |
| Unique | One of a kind; no degrees. | distinctive, or drop the intensifier |
| Utilize | Means use; the plain verb is better. | use |
| Very | Weak intensifier. | a stronger adjective or adverb |
| While | Means during; for contrast, use but. | during, a semicolon, or but |
| -wise | Only for manner, as in clockwise. | regarding, or in the manner of |
